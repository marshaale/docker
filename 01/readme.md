## Login

```shell
docker login -u youruser
```

## Build

```shell
docker build -t youruser/docker-01ex-app:latest .
```

## Run

```shell
docker run -it youruser/docker-01ex-app:latest
```

## Push

```shell
docker push youruser/docker-01ex-app:latest
```
